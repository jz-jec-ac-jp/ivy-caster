# ivy-caster 要件定義書

**プロジェクト名**: ivy-caster  
**目的**: Symantec Ghost Solution Suite の代替品開発  
**作成日**: 2026-02-21  
**更新日**: 2026-02-21  
**バージョン**: 2.0  
**技術スタック**: WPF (.NET 10) + C# 統一

---

## 1. プロジェクト背景

学内PCの管理に Symantec Ghost を使用しているが、以下の課題がある：

- Windows 7 でしか動作しない
- UIが非直感的で操作性が悪い
- PC のグループ管理（フォルダ管理）が困難
- 複数ネットワークセグメント（10.x.x.x）ごとに管理PCが必要

## 2. 現行運用フロー

1. **PC登録**: LAN内の有線PCを検出 → クライアント版Ghostをリモートインストール
2. **コマンド・ファイル転送**: NTP設定、EXEファイル等を管理PCから転送
3. **タスク管理**: 作業一覧からコマンド内容を確認・編集

## 3. 機能要件

| ID     | 機能名             | 説明                                                                   | 優先度 |
| ------ | ------------------ | ---------------------------------------------------------------------- | ------ |
| FR-001 | PC検出・登録       | LAN内PCの自動検出（ARP/Ping）、手動登録、ホスト名・OS・MAC自動取得     | 高     |
| FR-002 | エージェント配布   | MSIサイレントインストール、WMIによる初回展開（必須）、将来的な自動更新   | 高     |
| FR-003 | コマンド実行       | 単一/複数/グループ一斉実行、PowerShell/cmd対応、結果収集・DataGrid表示 | 高     |
| FR-004 | ファイル転送       | gRPCストリーミング転送、進捗表示、配布後自動実行、SHA256検証           | 高     |
| FR-005 | タスク管理         | タスクCRUD、テンプレート化・再利用、実行履歴管理                       | 高     |
| FR-006 | グループ管理       | WPF TreeView + ドラッグ&ドロップ、無制限ネスト、右クリックメニュー     | 中     |
| FR-007 | 複数セグメント対応 | 1台管理PCで複数セグメント管理、リレーエージェント方式                  | 中     |
| FR-008 | OS操作抽象化       | エージェントのOS依存処理を抽象化し、将来的なLinux対応を可能にする       | 中     |

## 4. 非機能要件

| ID      | 要件             | 説明                                                       |
| ------- | ---------------- | ---------------------------------------------------------- |
| NFR-001 | OS対応           | 管理コンソールはWindows 11対応、エージェントは将来Linux対応を考慮       |
| NFR-002 | 操作性           | WPFネイティブUI（TreeView + ListView + ContextMenu + D&D） |
| NFR-003 | 保守性           | C#統一言語、MVVM、CommunityToolkit.Mvvm、xUnitテスト       |
| NFR-004 | スケーラビリティ | 100台以上のPC管理                                          |
| NFR-005 | セキュリティ     | 認証・認可、gRPC TLS暗号化                                 |
| NFR-006 | 可用性           | エージェント自動再接続、障害時リトライ                     |

## 5. ステークホルダー

| 役割   | 説明                                                               |
| ------ | ------------------------------------------------------------------ |
| 管理者 | PCの管理操作を行うIT担当者                                         |
| 学生PC | .NET 10 Worker Service エージェントがインストールされた管理対象端末 |

## 6. 制約事項

- 学内LAN環境（有線LAN）での使用を前提
- 当面の管理対象は Windows PC のみ（エージェントは将来的に Linux 対応予定）
- インターネット接続は必須ではない（LAN内完結可能）
- .NET 10 Runtime が管理者PC・学生PCに必要（Self-Contained配布で回避可能）
